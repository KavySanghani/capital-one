Cloud Migration Architecture Progression

IT457 Theme 2 — Capital One Case Study Evolution across State 0, State A, and State B

Project Architecture Overview
Demonstration & Historical Benchmark Clarification: The sections below document the architectural progression delivered during our cloud migration study. State 0 is currently executing locally in Docker Compose as the active interactive project demonstration testbed. State A and State B represent historical completed deployment milestones that were benchmarked and subsequently terminated to eliminate ongoing cloud costs.

  • Status: Historical completed benchmark (resources terminated)

  • Database: PostgreSQL 16 container co-located on same EC2 VM

State B Historical Completed Deployment

Decoupled EC2 + Amazon RDS

EC2 App Tier Public Subnet (ap-south-1a)
→ private →
Amazon RDS Single-AZ (ap-south-1c)
  • Status: Historical completed benchmark (resources terminated)
  • App Host: Amazon EC2 c7i-flex.large (2 vCPU, 4 GiB RAM)
  • Database Tier: Single-AZ Amazon RDS PostgreSQL 16.15 (db.t4g.micro, 20 GiB GP3)
  • Deployment Mode: Single-AZ deployment (1 DB instance) for fair comparison & cost containment
  • Network Security: Isolated private DB subnet group (no public IP)
  • Operational Gain: AWS-managed DBMS provisioning, software patching, and storage maintenance
Modernization Benefit: Decoupled compute/database tiers, managed DBMS patching, and VPC isolation

State B Pricing Reconciliation & Transparency: The State B monthly projections reflect two distinct documented figures: the project report baseline of $80.99/month (EC2 $63.36 + RDS db.t4g.micro $17.63) and the AWS Pricing Calculator export dated November 14, 2026 of $124.38/month (EC2 $63.36 + RDS PostgreSQL $61.02). These figures differ because the AWS Pricing Calculator summary export does not expose enough configuration detail to identify the $43.39/month RDS difference. Both figures are presented transparently.
Short-Duration Lab Costs vs. Monthly Projections: Actual AWS billing incurred during our benchmarking was approximately $1.19 for State A (~13 hours total instance runtime) and approximately $0.28 for State B (~2.5 hours total EC2 and RDS runtime). These short-duration experimental run costs reflect brief benchmarking executions and must be clearly distinguished from continuous 730-hour theoretical monthly projections.
Implementation Effort Notice: All implementation effort figures (approx. 15 minutes for State 0, 1–2 hours for State A, and 2–3 hours for State B) are engineering estimates based on setup procedures and team handoffs, not stopwatch-measured timings.
